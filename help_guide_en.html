Introduction

Stream Dock M18 is a controller with 15 LCD keys and 3 side buttons. This app (its own driver, no official VSD software) lets you assign each key an image, a title and an action, organize them into scenes and pages, and trigger them with different gestures.

Two pieces worth knowing:
  • Configurator — the window where you design everything (keys, scenes, actions).
  • Server / tray — the process that talks to the M18 and runs the actions. It stays in the system tray even after you close the configurator; only “Exit” shuts it down.

Scenes, pages and keys

The configuration has three levels. Understanding them is the key to getting the most out of it:

Scene

A set of pages for a given context (for example “Work” and “Streaming”). You switch scenes with the side buttons or the Scene Shift action. One scene is the default scene (“home”): it loads on startup and is where the center button returns.

Page

A “board” of 15 keys. A scene can have several pages and you move between them with Previous/Next Page, Go to Page or a folder (Create Folder).

Key

Each position (0–14) can carry an image, a title (up to 3 lines), text/background colors, and an action. It can also have a second action via double-tap and take part in combos.

The device

The M18 has a 3×5 grid of LCD keys (positions 0 to 14) and 3 side buttons with no screen: left, mid, right.

Default side buttons: left = previous scene, mid = default scene (home), right = next scene. You can reassign them by clicking them in the configurator.
Important — the hardware only sends “key pressed / released”. There are no wheels, dials or touchscreen. Every gesture (tap, long-press, double-tap, combos) is built in software on top of that single signal.

Assigning an action to a key

  1. Drag an action from the library (right panel) onto a key in the grid.
  2. Double-click a configured key to edit it (keeps its title and icon).
  3. Right-click a key for its menu: copy, paste, clear, capture image, Double-tap and Combos (page).

In each key editor you can set a title, pick an icon from the gallery (or capture a screen area as the icon), and tweak colors and font.

Gestures: tap, long-press, double-tap and combos

Tap (short press)

Fires the key's main action. For normal keys it is instant.

Long-press (hold)

Some functions use holding for their main or secondary function. They are marked in the bottom-left corner:

  • ⟲ amber ring — long-press is required (e.g. Hold and Record, Sequence Repeat).
  • •• cyan dots — long-press does an extra function (e.g. Long Recorder; in the Calculator, +→×, −→÷, Back→clear).

Double-tap

Two quick taps (less than ~0.28 s apart) run a second action different from the main one. Marked with » green (top-right corner).

Trade-off: on a key with double-tap configured, its single tap is delayed ~0.28 s (it must wait for a possible second tap). Keys without double-tap respond instantly.
Example: a “Play/Pause” key whose double-tap opens YouTube. Right-click the key → Double-tap → pick the action.

Combos (2 keys)

Pressing two keys at once fires its own action and cancels the individual actions of those keys. Combos are per page. Member keys are marked with + purple (top-left corner).

Example: keys 1 and 2 together switch scene. Right-click any key → Combos (page) → pick Key A, Key B and the action → Add combo.
What works in double-tap/combo: “simple” actions —launch app, website, hotkey, text, multimedia, brightness, close, super-hotkeys, routine, audio, capture, scene/page switch… The stateful mini-apps (Timer, Calculator, recorders, Sequence Repeat, Alarm, Calendar, Reminder, To-Do) are not allowed as double-tap/combo, since they have their own press handling.

Managing scenes

  • Create / rename scenes from the scene bar (double-click to rename).
  • Default scene (home): double-click a scene's “home” button to make it the one that loads on startup and where the center side button returns.
  • Export a single scene to a .zip package (with its icons) to move it to another machine or share it. See Export / import.

Export / import (with icons)

Export produces a .zip package that includes your configuration and the actual icons (plus captures and custom fonts). So when you import it on another machine, everything restores exactly the same: icons are relocated and paths are rewritten automatically.

Export: Settings → Export → saves stream_dock_m18_config.zip.
Import: Settings → Import → choose the .zip (it also accepts old .json files, though those carry no icons).

Tray and autostart

  • The app registers to start with Windows and copies icons/config to your user folder the first time.
  • The server stays alive in the tray even after you close the configurator. Only Exit (tray menu) shuts it down.
  • From the tray you can open the configurator, toggle autostart and quit.

Troubleshooting

The M18 isn't detected. Use a USB-C data cable (not charge-only) and close the official VSD software if it's open: it can't be connected at the same time as this app. Try another USB port.
Icons don't show up after restoring. Import the .zip package (not a bare .json): the .zip carries the icons and relocates them. See Export / import.
A hotkey doesn't reach a game. Use Hotkey (sends by scancode, which games like DCS recognize). Note: capturing system shortcuts (e.g. Win+R) also triggers the system action.
Where does my data live? Settings → “Open folder” opens the folder with your config.json and icons/.
